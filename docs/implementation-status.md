The current v0.4 lineage has now been executed in approved restricted storage
from the selected clean source baseline. Validation, transformation, structured
analysis, candidate generation, manual disclosure attestation, independent
release verification, and a restricted results-integrated manuscript build have
completed for that baseline. The generated artifacts, verification records,
source provenance, timestamps, open text, and any respondent-level material
remain outside Git.

The release policy suppressed all non-eligible candidate summaries and allowed
only the disclosure-approved aggregate result fragment to enter the
results-integrated manuscript build. The manuscript source in Git remains
results-free and imports only the generated fragment during the restricted
attested build. The raffle archive remains a separate administrative record and
is not analysis input.
