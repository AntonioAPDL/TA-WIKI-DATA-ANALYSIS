# Decision record template

Use one record for every decision that can change analysis, privacy, release,
or manuscript interpretation. Keep restricted evidence and identities outside
Git; reference them by a non-sensitive internal identifier.

| Field | Record |
|---|---|
| Decision ID | `DEC-YYYY-NNN` |
| Status | draft / proposed / confirmed / implemented / verified / superseded |
| Decision date | YYYY-MM-DD |
| Authority role | Role only in tracked record |
| Scope | What this decision governs |
| Decision | Concise approved rule |
| Rationale | Why it is appropriate |
| Evidence reference | Non-sensitive reference or restricted-record ID |
| Affected artifacts | Code, metadata, table, manuscript, or release artifacts |
| Verification | Test, review, or commit reference |
| Review trigger | What future change invalidates this record |
