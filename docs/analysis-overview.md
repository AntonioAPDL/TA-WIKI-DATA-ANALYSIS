# Analysis overview

The [analysis specification](analysis-specification.md) is the controlling
technical document. It defines the descriptive scope, analytic cohort,
denominators, missingness rules, contribution-uncertainty requirements, qualitative
boundary, planned artifacts, and explicit nonclaims.

This study is a structured-only departmental descriptive survey/evaluation. It
does not support causal interpretation, an unverified response-rate
calculation, department-wide prevalence estimates, respondent-level routing
claims, or population-level generalization. Separate disclosure review is
required before any external/public results are shared.

## Questions examined

The study describes survey records' reported awareness and use of the TA Wiki,
perceived value, prior contribution, contribution-process perceptions, GitHub
perceptions, and selected features of a useful departmental teaching resource
within one departmental setting.

## What the study does not do

It does not compare interventions, estimate effects of the Wiki or related
activities, infer a population rate, verify respondent-level routing, or use
qualitative themes as manuscript evidence. Optional open-text responses are
handled through a separate restricted manual qualitative protocol.
